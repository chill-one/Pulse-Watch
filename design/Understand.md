<h1> Understand the product </h1>

<h3> Who uses it?</h3>
The targeted users are people that would like to monitor thier or other websites uptime.

<h3> What problem it solves? </h3>
The issue am trying to resolve is monitoring the given url and alerting the user on any fault with their url. As well as testing the latency of ther url response.

<h3> What actions the user performs </h3>
The user only needs to inform the system of what url they need to track from thier the system will do the rest.

<h3> What result the system provides </h3>
The system shall provide the uptime of the url, the response time of the url and incase of any fault alert the usre.
